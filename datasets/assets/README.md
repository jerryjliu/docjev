The fonts in `fonts/` reproduce the [LlamaIndex visual guidelines](https://www.llamaindex.ai/brand).

- Overused Grotesk Regular and Medium: derived from the official site's [variable font](https://www.llamaindex.ai/fonts/OverusedGrotesk-VF.woff2), instantiated at weights 400 and 500. Publisher: RandomMaerks. Original font license is retained.
- IBM Plex Mono Regular: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/ibmplexmono). Original SIL Open Font License is retained.

The copies were obtained from previously downloaded official brand assets, with source provenance recorded on September 5, 2026. PDF generators embed the font subsets. Office documents request Overused Grotesk by family name; install the provided font for identical rendering in applications that do not discover it automatically.
